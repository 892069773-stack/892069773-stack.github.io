智谱华章｜HRBP 招聘全板块与校招生 HR 面试

这段经历从单一岗位招聘进一步走向完整 HRBP 交付：负责部门 190+ 人团队的滚动招聘全流程，独立承担校招生 HR 面试；既要和业务拆清大模型算法、微调等技术门槛，也要覆盖 UI、测试、开发、数据工程、AI 产品经理等岗位，并统筹全国分公司的招聘节奏。

  • 负责部门 190+ 人团队的滚动招聘全流程，推进需求澄清、人才画像、开源初筛、面试协调、谈薪及 Offer / 入职，并独立承担校招生 HR 面试；累计开源 500+ 份简历，151 人一面、69 人二面、28 个 Offer，协助完成实习生定薪与 Offer 审批。

  • 围绕业务拆解岗位需求，维护候选人管理表（152 人）与需求台账（31 条）并周更招聘周报，完成 8 个岗位 JD 与社招招聘海报；参与清华深圳研究院校招，现场对接 200+ 人、添加 100 位清华候选人微信，沉淀校招人才池；开展市场薪酬调研与弹性薪酬方案，制定 BOSS 直聘账号购买与渠道投放策略，并用 Vibe Coding 优化简历筛选与候选人管理。
  • 维护 200+ 名员工合同、档案及人事台账，准备入职材料；负责工位规划、行政合规检查、资料打印、场地布置与拍摄，支持日常员工与办公运营。

03系统精筛

持续跟进面试、薪酬、Offer、入职与全国岗位调度。

Case 01

快手可灵 AI｜音频算法与数据智能岗位寻访

这段经历的难点不是“筛很多简历”，而是目标候选人本来就少。可灵 AI 音频智能中心关注音频算法、多模态生成、音视频联合生成等方向，后面也接触了数据智能中心相关岗位。很多候选人不会主动投递，只能从竞对团队、论文和公开线索里往回找。

500+AI 岗位简历筛选
5+XMind 人才脑图
20+专家线索触达
6 / 4已入职 / 待入职
  • 围绕阿里通义、字节 Seed、腾讯混元 / 天籁、百度文心一言等团队做人才 Mapping，后续扩展到月之暗面、阶跃星辰、智谱等新兴团队，独立产出 5+ 张 XMind 人才脑图与多份可触达 List。
  • 从招聘系统和人才库抽取候选人经历，追踪其在目标团队期间发表的论文，再通过 Google Scholar、论文主页、作者拼音、学术主页和合作关系扩展线索。
  • 把线索带回脉脉、人才库和公开渠道搜索，找到可联系候选人后，跟进微信、电话、面试和长期关系维护。
  • 通过 Paper 作者链路整理 20+ 可联系专家，触达蚂蚁百灵、百度文心一言、腾讯混元、字节 Seed 等候选人，并整理 2025-2026 年音视频联合生成大模型算法人才历史与候选人文档。
  • 参与音频算法社招、校招及实习生岗位招聘，累计筛选 500+ 份简历，协助完成 5 场实习生 HR 面及面评，推动 25+ 位候选人进入面试，8 位社招算法与 2 位校招候选人接收 Offer，4 人待入职、6 人已入职。
  • 承接数据智能中心大模型数据策略专家、多模态链路质量专家、AI 测试开发、数据平台开发等岗位招聘；独立撰写 AI 质量检测实习生 JD，并在 BOSS 等渠道触达 5+ 数据策略运营候选人进入面试。
  • 同时维护 4 张招聘台账和 2 张音频算法人才 List，每天同步 Mapping 进展、触达状态、面试节点和候选人反馈。
01 先定目标池

不是泛搜“算法工程师”，而是按团队、方向、论文和项目经历建立目标名单。

02 用论文反查人

从论文作者、合作教授、学术主页和同组成员里找可能相关的人，再回到招聘平台验证。

03 把关系接起来

触达后不只问意向，也记录候选人动机、竞对机会、薪酬预期和可沟通窗口。

04 盯住推进节点

面试、业务反馈、收薪、Offer 沟通和入职材料都要持续跟，不能只停在“找到人”。

Case 02

AI-HR 智能招聘与猎聘系统｜从实习路径长出来的工具

这个 Demo 来自快手实习里的真实路径：竞对团队、论文、学术主页、候选人画像、触达记录和面试节点。它解决的是一个很实际的问题：线索多了之后，怎么别乱、别漏、别只靠脑子记。

Source竞对 / 论文 / 主页
Search模糊姓名 / 关联作者
Match画像 / 岗位关键词
Pipeline触达 / 面试 / Offer
  • 系统分成智能招聘和智能猎聘两条链路，其中猎聘模块更贴近我的实习产出：人才发现、公开成果检索、候选人画像和流程记录。
  • 候选人不是只看姓名和公司，而是把论文、项目经历、方向关键词、团队背景和可触达路径放在一起看。
  • 招聘管理部分衔接岗位需求、面试评估、触达记录和 Offer 节点，让猎聘动作可以继续往后走。
  • 这个项目也是我第一次把招聘经验和 Vibe Coding 接起来：先写清楚流程，再把页面、交互和数据结构做出来。

Case 03

未来鹅｜把成长信号变成招聘上下文

未来鹅的核心想法很简单：学生大三求职时，很多重要信号其实大一大二就出现了，只是没人记录。这个 Demo 不是预测谁一定会成功，而是记录选择、任务、反馈和成长轨迹，让招聘方看到更完整的上下文。

大一性格测评 / 信号初建
大二任务练习 / 能力记录
大三岗位雷达 / 面试预热
大四简历转化 / 决策辅助
  • 产品用“信号星图”记录学生选择、任务和成长证据，让成长过程不只停留在最终简历上。
  • 岗位雷达会基于过往信号给出岗位方向和匹配解释，每一条建议都能追溯到具体记录。
  • 启明作为陪伴角色，贯穿测评、结果、成长、实验室和岗位匹配，负责把冷冰冰的评估变成一段持续对话。
  • 我在这个项目里重点做产品概念、用户路径、招聘方视角和演示原型推进，也借它练了多轮提示、视觉和交互迭代。

Case 04

Vibe Coding｜从工具试用到独立做页面和 Demo

我一直喜欢探索 Vibe Coding。最早从 Claude Code 开始，后来试过 VS Code 插件，也用过 Claude Code Opus 4.7、Opus 4.8、Fable5、DeepSeek V4 Pro，现在主要用 Codex 在本机读项目、改代码、检查问题和部署。

Claude CodeVS Code 插件Opus 4.7 / 4.8Fable5DeepSeek V4 ProCodex
  • 我用这些工具做过个人主页、AI-HR Demo、未来鹅、移动端问题排查、下载兼容处理和静态站部署。
  • 我慢慢意识到，工具本身不是作品，关键是先把业务问题讲清楚：目标是谁、输入是什么、输出是什么、哪些地方必须验证。
  • Claude Code 更像早期搭结构和做复杂页面的伙伴；VS Code 插件适合边写边改；DeepSeek 更适合帮我做研究和方案拆解；Codex 更适合接管本地项目，读文件、改代码、跑检查、部署。
  • 这条线也反过来影响我的招聘理解：我会更愿意把候选人、岗位、流程和工具放在一起看，而不是只看某一个关键词。
